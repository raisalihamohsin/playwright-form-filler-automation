============================================
    FORM FILLER AUTOMATION
============================================

Ye project Playwright ka use karke ek registration form ko automatically fill karta hai.

-------------------------------------------------
FEATURES
-------------------------------------------------
- Personal Information (Name, Address, Email, Phone)
- Gender Selection
- Hobbies (Checkboxes)
- Languages (Custom Dropdown)
- Skills (Native Dropdown)
- Country (Select2 Dropdown)
- Date of Birth
- Screenshot
